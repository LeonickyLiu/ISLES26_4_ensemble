# Frozen nnU-Net metadata

This directory contains only derived nnU-Net JSON metadata. It does not contain
medical images, labels, predictions, or model checkpoints.

- `Dataset004_ATLAS3_RAW/` contains the binary-label dataset description,
  fingerprint, standard plan, ResEncM plan, and exact five-fold split.
- `Dataset005_ATLAS3_RAW_MSL/` contains the corresponding metadata for the
  multi-size-label dataset generated by `training/data/create_msl_dataset_raw.py`.

Dataset004 and Dataset005 deliberately use the same split. Both copies of
`splits_final.json` have SHA256
`5b89628f3e4ecc196967578c6b3813fb9099063ffc6c4d4c3a8af348fc1fc2c7`.

These files were generated from the organizer-provided training set including
the corrections released on 2026-07-28. Obtain the underlying data from the
challenge organizers; it is not licensed or redistributed by this repository.
